# LLM Zoomcamp

Hands-on projects and notes from the LLM Zoomcamp by [Alexey Grigorev](https://github.com/alexeygrigorev) and the [DataTalks.Club](https://github.com/DataTalksClub) team.

This repository follows the 2026 cohort (starting June 8, 2026) and contains exercises and experiments. The course builds a complete LLM application from a first working RAG pipeline through evaluation, monitoring, and deployment.

## Course Overview

The course covers practical LLM application development, including:

- Building RAG pipelines from scratch
- Vector search and semantic retrieval
- AI agents and function calling
- Evaluation of retrieval and answer quality
- Monitoring deployed LLM systems
- A capstone project with peer review

## Tech Stack

Tools and technologies used throughout the course:

- Python
- OpenAI API
- Elasticsearch
- MinSearch
- Qdrant
- Docker
- PydanticAI
- Jupyter Notebooks

## Repository Structure

The repository is organized by module:

```text
.
├── 01-intro              # RAG basics, OpenAI API, Elasticsearch
├── 02-agents             # Agentic RAG, function calling, PydanticAI
├── 03-vector-search      # Embeddings, semantic search, hybrid retrieval
├── 04-evaluation         # Retrieval metrics, LLM-as-a-Judge
└── 05-monitoring         # Traces, feedback, production quality
```
